# Linksee 通知链路演示说明

更新时间：2026-06-20

## 当前通知分层

Linksee 目前把通知分成两类持久化来源，并在前端顶部聊天按钮的“系统通知”层级中统一展示：

| 层级 | 落点 | 是否落库 | 前端展示 |
| --- | --- | --- | --- |
| 课程/小组系统消息 | `chat_messages`，归属 `course:{courseId}` 或 `group:{groupId}` 会话 | 是 | 课程公告、小组系统消息、批阅反馈、成绩发布 |
| 用户级通知 | `user_notifications` | 是 | 离线可回查，顶部系统通知层级展示 |

说明：课程归档、项目归档时，“删除会话”按数据安全口径实现为 `chat_conversations.status = archived`，不是物理删除聊天记录。

## 用户级通知表

新增表：`user_notifications`

用途：

- 保存不适合写入课程/小组聊天的个人通知。
- 支持用户离线后再次登录补拉。
- 支持通知已读、全部已读和未读数量统计。

主要字段：

| 字段 | 含义 |
| --- | --- |
| `userId` | 接收通知的用户 |
| `type` | 通知类型，如 `minitask.due_soon` |
| `title` / `content` | 通知标题和内容 |
| `scopeType` / `scopeId` | 可选关联层级，如课程、小组 |
| `courseId` / `assignmentId` / `groupId` / `miniTaskId` | 可选业务关联 |
| `relatedEventId` | 关联事件 ID，用于幂等去重 |
| `readAt` | 已读时间，空表示未读 |

接口：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `GET` | `/api/v1/notifications?limit=50&offset=0&unreadOnly=true` | 查询当前用户通知 |
| `POST` | `/api/v1/notifications/:notificationId/read` | 标记单条通知已读 |
| `POST` | `/api/v1/notifications/read-all` | 标记当前用户通知全部已读，可按 `scopeType/scopeId` 限定 |

## 已实现链路

| 触发动作 | 后端处理 | 通知内容 | 层级 |
| --- | --- | --- | --- |
| 课程从 `draft` 切到 `active` | 写课程系统消息并推送课程事件 | `系统通知：课程《课程名》已开始` | 课程会话 |
| 课程从 `active` 切到 `archived` | 写课程系统消息；归档课程会话；归档课程下小组和小组会话 | `系统通知：课程《课程名》已结束` | 课程会话 |
| 项目切到 `active` | 写课程系统公告 | 项目已开启，请查看要求并开始协作 | 课程会话 |
| 项目切到 `archived` | 写课程系统公告；归档项目下小组和小组会话 | 项目已结束，相关小组会话已归档 | 课程会话 |
| 创建或开放阶段 | 写课程系统公告 | 阶段创建、更新或开放说明 | 课程会话 |
| 小组正式成立 | 创建或启用小组会话并写系统消息 | 小组已确认成组 | 小组会话 |
| 删除组长后自动更换组长 | 写小组系统消息 | 组长自动变更说明 | 小组会话 |
| 教师/助教提交批阅反馈 | 更新提交状态，推送事件，写小组系统消息 | 批阅人、结论、批语摘要 | 小组会话 |
| 教师发布成绩 | 更新成绩为 `published`，推送事件，写小组系统消息 | 发布人和分数 | 小组会话 |
| MiniTask 创建/更新且有负责人 | 小组消息中带 `mentions` | 自动 @ 负责人 | 小组会话 |
| MiniTask 截止前 1 天、截止前 1 小时、已逾期 | 写 `user_notifications`，同时推送 `system.notification.created` | 截止提醒标题、任务名、截止时间 | 用户级通知 |

## 前端展示

顶部聊天按钮中新增“系统通知”层级，展示两类数据：

- 会话内系统消息：来自课程会话和小组会话中的系统公告、批阅反馈、成绩发布等。
- 用户级通知：来自 `/api/v1/notifications`，离线后仍可补拉。

点击用户级通知后会调用已读接口；如果通知能匹配到课程或小组会话，会同时打开对应会话。

## 演示建议

1. 激活课程：课程会话出现“课程已开始”系统消息。
2. 开放阶段：课程会话出现阶段开放公告。
3. 批阅反馈：小组会话出现“谁批阅、什么状态、批语是什么”的系统消息。
4. 发布成绩：小组会话出现成绩发布系统消息。
5. MiniTask 截止提醒：用户离线后重新登录，顶部系统通知中仍可看到截止提醒。
6. 归档项目或课程：相关课程/小组会话状态变为归档，不再作为正常协作入口。

## 仍待后续增强

- 助教绑定/解绑、教师指派/移除等管理通知可以继续接入 `user_notifications`，不进入课程群聊。
- 邮件、企业微信等外部通知本轮不做。
- 成绩调整前端入口本轮不做；若后续开放，应补充成绩详情审计展示。
