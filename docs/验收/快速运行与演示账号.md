# 快速运行与演示账号

本文面向第一次本地运行、课堂演示和验收准备。所有命令均在仓库根目录执行。

## 1. 环境要求

- Node.js：建议 LTS 版本。
- Docker Desktop：需要先启动 Docker daemon。
- npm：随 Node.js 安装，用于安装依赖和运行脚本。

## 2. 第一次运行

```bash
npm install
cp infra/docker/.env.example infra/docker/.env
npm run dev:deps:up
npm run prisma:generate -w @linksee/api
npm run prisma:db:push -w @linksee/api
node scripts/验收/seed-smoke.mjs
npm run start:auth -w @linksee/api
```

Windows PowerShell 可用：

```powershell
Copy-Item infra/docker/.env.example infra/docker/.env
```

## 3. 访问地址

- 登录页：`http://localhost:3001/app/login.html`
- 健康检查：`http://localhost:3001/health`
- Demo 状态页：`http://localhost:3001/demo/status.html`

1. 教务查看课程和成员。

## 6. 常见问题

- Docker daemon 未运行：先打开 Docker Desktop，再执行 `npm run dev:deps:up`。
- 登录失败：确认已执行 `npm run prisma:db:push -w @linksee/api` 和 `node scripts/验收/seed-smoke.mjs`。
- 数据库未初始化：重新执行 Prisma generate 与 db push。
- 没有测试账号：重新执行 `node scripts/验收/seed-smoke.mjs`。
- 端口 `3001` 被占用：关闭占用该端口的进程后重新启动服务。
- 浏览器缓存导致页面没有更新：强制刷新页面，或打开无痕窗口重新登录。
