# 验收数据说明

## 文件清单

- `scripts/验收/excel.mjs`：生成 Excel 和 CSV 导入文件。
- `data/excel/学生账号导入.xlsx`：学生导入文件。
- `data/excel/教师账号导入.xlsx`：教师导入文件。
- `data/excel/助教账号参考.xlsx`：助教账号归属参考表；助教通常通过教师/教务流程创建，不作为通用导入表。
- `data/excel/课程参考清单.xlsx`：20 门已有验收课程参考表。
- `data/excel/课程名单-ACC-2026-01.xlsx` 到 `data/excel/课程名单-ACC-2026-20.xlsx`：每门课程的学生名单导入文件。
- `scripts/验收/seed-large.mjs`：正式验收用的大样本直接写库脚本。
- `scripts/验收/seed-smoke.mjs`：小样本冒烟脚本，保留用于快速验证。

## 数据覆盖

- 用户：1 个教务、20 个教师、30 个助教、200 个学生。
- 身份信息：通用 profile、学生学籍、教师档案、助教归属。
- 课程：20 门已有验收课程。
- 项目：每门课程最多 2 个项目；其中 4 门课程 2 个项目，其余 16 门课程 1 个项目。
- 阶段：覆盖 open、closed、planned。
- 小组：覆盖多课程、多项目分组。
- minitask：覆盖 todo、in_progress、done、cancelled。
- 会话：课程会话和小组会话。
- 提交与批阅：覆盖 submitted、under_review、needs_changes、reviewed、approved。
- 成绩：覆盖 draft、published、adjusted 日志。

## 运行方式

生成 Excel/CSV：

```powershell
node scripts/验收/excel.mjs
```

直接写库，正式验收：

```powershell
node scripts/验收/seed-large.mjs
```

直接写库，快速冒烟：

```powershell
node scripts/验收/seed-smoke.mjs
```

写库脚本会清理并重建固定验收账号、课程号和关联数据。它不会清理不在验收 ID/课程号范围内的业务数据。

## 大样本范围

- 教务账号：`2099000001`
- 教师账号：`2099000101` 到 `2099000120`
- 助教账号：`2099000201` 起，共 30 个；每个教师 1-2 个助教。
- 教师 `2099000101` 只有 1 个助教，可用于后续“开通助教/新增助教”验证。
- 学生账号：`2099001001` 到 `2099001200`
- 课程号：`ACC-2026-01` 到 `ACC-2026-20`

## 新建演示建议

已有数据用于验收列表、检索、编辑、批阅和成绩发布。新建能力不要复用已有课程号或项目名，建议现场创建：

- 新课程：`ACC-2026-NEW`
- 新项目：`现场新建项目`
- 新阶段：`现场新建阶段`
- 新助教：可在教师 `2099000101` 名下追加创建，用于验证只有一个助教的老师继续开通助教。
