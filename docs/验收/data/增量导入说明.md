# 增量导入说明

这批文件用于在现有正式验收数据基础上，继续导入一组新的老师、学生和课程名单，方便现场演示“新增账号、建课、导入学生、老师创建助教与项目阶段、小组协作”链路。

## 文件位置

- `docs/验收/data/excel/增量导入-学生账号.xlsx`
- `docs/验收/data/excel/增量导入-教师账号.xlsx`
- `docs/验收/data/excel/增量参考-助教账号.xlsx`
- `docs/验收/data/excel/增量参考-课程清单.xlsx`
- `docs/验收/data/excel/增量名单-ACC-LIVE-01.xlsx`
- `docs/验收/data/excel/增量名单-ACC-LIVE-02.xlsx`

同目录也同步生成了 `.csv` 版本。

## 当前口径

`docs/验收/data` 目录现在只保留“不会与脚本种子数据冲突”的增量导入文件。

脚本 `scripts/验收/seed-large.mjs` 预先写入的是正式验收主数据。
这里的 Excel 仅用于现场继续演示导入，不再保留会与 `ACC-2026-*`、`209900...` 主数据冲突的旧表。

## 建议用途

### 1. 教务端导入学生

使用：

- `增量导入-学生账号.xlsx`

表头符合系统当前导入要求：

- 一卡通号
- 姓名
- 年级
- 专业
- 行政班
- 届次

### 2. 教务端导入教师

使用：

- `增量导入-教师账号.xlsx`

表头符合系统当前导入要求：

- 一卡通号
- 姓名
- 学院
- 职称
- 工号
- 研究方向

### 3. 教务端课程名单导入

先由教务手动创建课程：

- `ACC-LIVE-01`
- `ACC-LIVE-02`

然后分别导入：

- `增量名单-ACC-LIVE-01.xlsx`
- `增量名单-ACC-LIVE-02.xlsx`

课程名单导入只需要两列：

- 姓名
- 一卡通号

### 4. 助教创建参考

`增量参考-助教账号.xlsx` 不是直接给教务导入的主表，而是给老师现场手工创建助教子账号时参考。

建议老师创建：

- `2099010201` / 验收助教甲，归属 `2099010101`
- `2099010202` / 验收助教乙，归属 `2099010102`

## 建议演示主课程

优先使用：

- `ACC-LIVE-01`

它适合展示：

- 教务导入学生
- 老师创建助教并绑定课程
- 老师创建项目和阶段
- 学生创建小组和提交材料
- 助教批阅
- 老师最终定分

## 默认口径

这些增量账号与现有 `209900...` 验收主数据不同，不会与当前正式种子数据冲突，可以放心叠加导入。
