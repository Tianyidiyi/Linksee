# 当前交付状态

更新时间：2026-06-18

## 一、项目阶段

项目当前处于“后端主链路基本成型，前端收口与验收准备并行推进”的阶段。

当前重点不是继续扩展能力，而是：

1. 统一产品、接口、状态和通知口径。
2. 收紧教师端和助教端批阅工作台。
3. 用真实接口与真实数据完成验收演示。
4. 补齐关键测试、部署说明和文档事实源。

## 二、当前已形成的主链路

### 1. 教务端
- 课程创建、编辑、状态流转
- 教师绑定、学生导入、成员维护
- 用户创建、批量导入、重置密码

### 2. 教师端
- 课程进入与项目浏览
- 项目、阶段创建和编辑
- 小组创建、编辑、一键分组、确认成组
- 助教绑定与解绑
- 查看提交、查看批阅、保存草稿、发布成绩

### 3. 助教端
- 查看课程、项目、阶段与小组提交
- 查看提交内容与附件
- 提交批阅结果

### 4. 学生端
- 课程查看
- 小组创建、申请加入、查看组内信息
- 阶段提交、查看提交状态

## 三、当前已确认的正式口径

1. 课程状态：`draft -> active -> archived`
2. 项目状态：`draft -> active -> archived`
3. 阶段状态：`planned -> open -> closed -> archived`
4. 小组状态：`forming -> active -> archived`
5. 阶段删除语义：当前为“归档阶段”，不是物理删除
6. 课程激活前置条件：至少一位教师、至少一位已绑定助教
7. 助教解绑权限：由课程教师执行
8. 评分草稿保存：创建或覆盖，不重复生成多条草稿

## 四、当前仍需收口的重点

### P0
1. 教师与助教批阅到教师发布成绩的完整真实链路验证
2. 成绩草稿、发布成绩与回显状态稳定性复查
3. 小组调整后 hero 区、表格、成员和未分组列表同步一致性
4. 通知规则系统复查
5. 真实验收数据准备

### P1
1. mock 代码清理
2. 前端轻量回归测试
3. 后端关键接口测试补齐
4. Docker 打包与服务器部署说明收尾

## 五、当前已知风险

1. 文档仍可能落后于最近一轮快速 UI 与联调修改。
2. 通知逻辑容易出现漏发或重复发，需要单独核对。
3. 批阅页与成绩页的最终回显必须继续在真实数据上复验。
4. 验收若切换到真实数据，残留 mock 分支必须尽快清理。
