# 课程后端接口总览

更新时间：2026-06-18

说明：

1. 本文档用于快速查看当前仍对外开放、且与现有前端链路相关的课程域接口。
2. 具体字段、请求体与响应体以 `docs/api/openapi/linksee-v1.yaml` 和运行代码为准。
3. 已归档或不再使用的联调说明、旧版草案不再放入本文件。
4. 本文档更关注“当前真实会走的链路”，不追求把所有历史接口一并堆进来。

## 零、当前最常用的真实链路

### 1. 教务主链路
- 创建课程：`POST /api/v1/courses`
- 绑定教师：`POST /api/v1/courses/:id/teachers`
- 导入学生：`POST /api/v1/courses/:id/members/batch`
- 激活课程：`PATCH /api/v1/courses/:id`

### 2. 教师主链路
- 创建项目：`POST /api/v1/courses/:courseId/assignments`
- 创建阶段：`POST /api/v1/assignments/:assignmentId/stages`
- 创建或调整小组：`POST /api/v1/assignments/:assignmentId/groups`
- 确认分组并创建群聊：`POST /api/v1/assignments/:assignmentId/groups/conversations`
- 查看待批阅：`GET /api/v1/courses/:courseId/pending-reviews`
- 保存评分草稿：`POST /api/v1/submissions/:submissionId/grade-drafts`
- 发布成绩：`POST /api/v1/grades/:gradeId/publish`

### 3. 助教主链路
- 查看课程与提交：`GET /api/v1/courses/:courseId/pending-reviews`
- 开始批阅：`POST /api/v1/submissions/:submissionId/reviews/start`
- 提交批阅：`POST /api/v1/submissions/:submissionId/reviews`

### 4. 学生主链路
- 查看课程：`GET /api/v1/courses`
- 创建小组：`POST /api/v1/assignments/:assignmentId/groups`
- 申请入组：`POST /api/v1/groups/:groupId/join-requests`
- 提交阶段成果：`POST /api/v1/stages/:stageId/groups/:groupId/submissions`

## 一、课程

状态：`draft | active | archived`

当前主权限：
- 教务：创建、编辑、激活、归档课程
- 教师：访问自己课程，绑定或解绑自己名下助教
- 助教：访问已绑定课程
- 学生：访问自己参与的课程

- `GET /api/v1/courses`：课程列表
- `POST /api/v1/courses`：创建课程
- `GET /api/v1/courses/:id`：课程详情
- `PATCH /api/v1/courses/:id`：更新课程
- `GET /api/v1/courses/:id/teachers`：课程教师列表
- `POST /api/v1/courses/:id/teachers`：绑定教师
- `PATCH /api/v1/courses/:id/teachers/:userId`：更新教师关系
- `DELETE /api/v1/courses/:id/teachers/:userId`：解绑教师
- `GET /api/v1/courses/:id/assistants`：助教列表
- `POST /api/v1/courses/:id/assistants`：绑定助教
- `DELETE /api/v1/courses/:id/assistants/:assistantUserId`：解绑助教
- `GET /api/v1/courses/:id/members`：课程学生列表
- `POST /api/v1/courses/:id/members`：添加单个学生
- `POST /api/v1/courses/:id/members/batch`：批量导入学生
- `DELETE /api/v1/courses/:id/members/:userId`：移除学生

## 二、项目

状态：`draft | active | archived`

当前主权限：
- 教师、助教：查看与管理课程内项目
- 学生：仅查看已开放课程中的可见项目

- `POST /api/v1/courses/:courseId/assignments`：创建项目
- `GET /api/v1/courses/:courseId/assignments`：项目列表
- `GET /api/v1/assignments/:assignmentId`：项目详情
- `PATCH /api/v1/assignments/:assignmentId`：更新项目
- `DELETE /api/v1/assignments/:assignmentId`：删除项目
- `POST /api/v1/assignments/:assignmentId/materials`：上传项目附件
- `DELETE /api/v1/assignments/:assignmentId/materials`：删除项目附件

## 三、阶段

状态：`planned | open | closed | archived`

当前主权限：
- 教师、助教：查看与管理阶段
- 学生：仅查看已开放课程/项目下的可见阶段

- `GET /api/v1/assignments/:assignmentId/stages`：阶段列表
- `POST /api/v1/assignments/:assignmentId/stages`：创建阶段
- `GET /api/v1/stages/:stageId`：阶段详情
- `PATCH /api/v1/stages/:stageId`：更新阶段
- `DELETE /api/v1/stages/:stageId`：归档阶段
- `POST /api/v1/stages/:stageId/materials`：上传阶段附件
- `DELETE /api/v1/stages/:stageId/materials`：删除阶段附件

说明：`DELETE /api/v1/stages/:stageId` 当前语义是“归档阶段”，不是物理删除。

## 四、小组

状态：`forming | active | archived`

当前主权限：
- 学生：创建组、申请入组、查看本组
- 组长：审批申请、发起组长转让
- 教师、助教：手动调整成员、确认成组

- `GET /api/v1/assignments/:assignmentId/groups`：小组列表
- `GET /api/v1/assignments/:assignmentId/my-group`：查询当前用户在该项目下的小组
- `POST /api/v1/assignments/:assignmentId/groups`：创建小组
- `POST /api/v1/groups/:groupId/members`：教学侧手动加成员
- `DELETE /api/v1/groups/:groupId/members/:userId`：移除成员
- `POST /api/v1/assignments/:assignmentId/groups/conversations`：确认分组后批量创建或补齐群聊

### 小组申请与组长转让

- `POST /api/v1/groups/:groupId/join-requests`：学生申请加入小组
- `GET /api/v1/groups/:groupId/join-requests`：查看入组申请
- `POST /api/v1/group-join-requests/:requestId/approve`：同意入组申请
- `POST /api/v1/group-join-requests/:requestId/reject`：拒绝入组申请
- `POST /api/v1/groups/:groupId/leader-transfer-requests`：发起组长转让
- `POST /api/v1/group-leader-transfer-requests/:requestId/accept`：接受组长转让
- `POST /api/v1/group-leader-transfer-requests/:requestId/reject`：拒绝组长转让

## 五、协作与聊天

当前主权限：
- 课程消息：课程成员可读，教学侧具备更高管理能力
- 小组消息：组内成员可读写

- `GET /api/v1/courses/:courseId/messages`：课程消息列表
- `POST /api/v1/courses/:courseId/messages`：发送课程消息
- `GET /api/v1/groups/:groupId/messages`：小组消息列表
- `POST /api/v1/groups/:groupId/messages`：发送小组消息

## 六、提交与批阅

提交状态：`not_submitted | submitted | under_review | needs_changes | approved | rejected | reviewed`

当前主权限：
- 学生：提交、查看本组提交
- 助教、教师：查看提交、下载附件、批阅

- `POST /api/v1/stages/:stageId/groups/:groupId/submissions`：创建阶段提交
- `GET /api/v1/stages/:stageId/groups/:groupId/submissions`：获取提交记录（含附件元数据）
- `GET /api/v1/submission-files/:fileId/download-url`：获取提交附件下载地址
- `POST /api/v1/submissions/:submissionId/reviews/start`：开始批阅
- `POST /api/v1/submissions/:submissionId/reviews`：提交批阅
- `PATCH /api/v1/reviews/:reviewId`：更新批阅
- `POST /api/v1/submissions/:submissionId/mark-reviewed`：未提交人工结案
- `GET /api/v1/courses/:courseId/pending-reviews`：待批阅列表
- `GET /api/v1/courses/:courseId/dashboard`：教师课程看板

当前下载链路说明：

1. 提交记录接口返回附件元数据与下载路径。
2. 前端通过 `GET /api/v1/submission-files/:fileId/download-url` 获取真实下载地址。
3. 下载能力属于当前真实链路的一部分，不再依赖 mock。

## 七、评分

评分状态：`draft | published`

当前主权限：
- 助教、教师：保存评分草稿
- 教师：发布成绩、调整已发布成绩
- 学生：仅查看已发布成绩

- `POST /api/v1/submissions/:submissionId/grade-drafts`：创建或覆盖评分草稿
- `PATCH /api/v1/grade-drafts/:gradeId`：更新评分草稿
- `POST /api/v1/grades/:gradeId/publish`：发布单条成绩
- `PATCH /api/v1/grades/:gradeId`：调整已发布成绩
- `GET /api/v1/stages/:stageId/groups/:groupId/grade`：查询单组单阶段成绩
- `GET /api/v1/courses/:courseId/grades`：课程成绩列表
- `GET /api/v1/courses/:courseId/grade-drafts`：课程成绩草稿列表
- `GET /api/v1/courses/:courseId/pipeline-health`：课程流水线健康检查

## 八、当前应注意的业务口径

1. 课程激活前必须已具备至少一位课程老师和至少一位已绑定助教。
2. 助教解绑应由课程老师执行，不由教务直接执行。
3. 小组群聊应在分组调整完成后，由教学侧确认创建，不应在学生组队过程中提前建立。
4. 评分草稿接口当前采用创建或覆盖语义，前端重复保存不会生成多条草稿。
5. 已删除的小组导出、评审导出、成绩导出等未使用接口，不再纳入当前正式链路。
6. 当前验收重点应围绕真实课程、真实小组、真实提交、真实批阅与真实评分回显展开。

## 九、当前不作为主线的能力

以下接口或能力后端可能存在，但不属于当前最优先验收主线：

1. 已发布成绩再次调整的复杂流程
2. 组号重排等小组增强管理能力
3. 大量导出与报表型接口
